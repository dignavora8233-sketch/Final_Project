# 🦠 COVID-19 Data Analysis Project

## 📌 About the Project

The COVID-19 Data Analysis project is developed using Python to analyze COVID-19 cases, recoveries, and deaths across different countries. It uses data analysis libraries and visualization techniques to understand trends and patterns in the dataset.

## 🎯 Project Objectives

* Analyze COVID-19 data using Pandas.
* Perform statistical calculations using NumPy.
* Visualize global COVID-19 trends.
* Compare COVID-19 cases across countries.
* Study the relationship between government intervention and new cases.
* Create interactive menu-based analysis.

## 🛠️ Technologies Used

| Technology | Purpose                   |
| ---------- | ------------------------- |
| Python     | Programming               |
| Pandas     | Data manipulation         |
| NumPy      | Numerical calculations    |
| Matplotlib | Data visualization        |
| Seaborn    | Statistical visualization |

## ✨ Key Features

* **Statistical Analysis:** Calculate mean, median, maximum, and minimum daily cases.
* **Global Trends:** Visualize cumulative cases, recoveries, and deaths.
* **Country Comparison:** Compare the top 5 countries by cumulative cases.
* **Intervention Analysis:** Explore government intervention scores and new cases.
* **Country Trends:** Display cumulative cases over time for top countries.
* **Menu-Driven System:** Select analysis options from a simple menu.

## ⚙️ Installation and Setup

**Step 1: Install Python libraries**

```bash
pip install numpy pandas matplotlib seaborn
```

**Step 2: Keep the dataset**

Place `COVID19_Data_Analysis_Dataset.csv` in the same folder as the Python program.

**Step 3: Run the project**

```bash
python covid_analysis.py
```

**Step 4: Select an option**

Enter a menu number to view statistical results or generate visualizations.
